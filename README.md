# Chem-Eng Projects

This is the hub for **process engineering** projects: the general philosophy and discussion that applies across *multiple* process-engineering projects, with links out to each specific project's own repo.

## Projects

| Project | Description |
|---|---|

## Wiki

The [chem-eng-projects Wiki](https://github.com/second-hand-tigers/chem-eng-projects/wiki) holds the general process-engineering philosophy, shared conventions, and cross-project reference material.

## What Lives Here vs. What Lives in Each Project Repo

| Here (`chem-eng-projects`) | Each project repo (e.g. `chem-eng-projects-MogasDebenz`) |
|---|---|
| General process-engineering philosophy and discussion | Project-specific milestones and Issues |
| Cross-project conventions (e.g. how BFDs/PFDs are used, stakeholder-engagement approach) | All team communication and mock stakeholder conversations, captured in Issue threads |
| Landing page linking to all projects | Project-specific Wiki (job aids, model version changelog, and other knowledge capture) |
| | The actual flowsheet model, PFDs, and deliverables for that project |

Each project repo is the complete working record for that project — not just its final deliverables, but the discussion, decisions, and knowledge capture that produced them. If something applies to *how you approach any process-engineering project* — not just one — it belongs in this repo's Wiki. If it's specific to one project's design, schedule, deliverables, or history, it belongs in that project's own repo.

## Why Multiple Fictional Projects, One Shared Approach

Each project here is a self-contained fictional scenario, but they share a common teaching goal: that project success depends as much on stakeholder engagement and communication as on technical skill. Rather than duplicating that philosophy and the associated conventions (milestone structure, versioning format, GitHub-App persona setup) in every project repo, they're documented once here and referenced from each project.
