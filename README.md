# Project Examples and Templates

This repository serves as the central directory for example chemical engineering design projects. Each project repository demonstrates the full lifecycle of a capstone-style engineering design effort, from early ideation through final optimization and sustainment.

## Purpose
This hub provides structured access to project workflows and documentation templates covering:

- Project ideation and concept generation  
- Screening and selection of viable design options  
- Flowsheet development and modeling  
- Model validation and sensitivity analysis  
- Economic evaluation and optimization  
- Post-project sustainment and applied use-case development
